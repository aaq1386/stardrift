# STARDRIFT: Space Paddle

A space-themed arcade brick breaker built with Python and Pygame.

Control your paddle, launch energy balls, destroy waves of bricks, collect power-ups, earn credits, and upgrade your equipment as you progress through increasingly challenging sectors.

## Features

- **Arcade gameplay** — paddle movement, ball physics, brick collisions, and progressive levels.
- **Space-inspired visuals** — a dark cosmic background, glowing colors, and procedural visual effects.
- **Progression system** — advance through sectors, earn rewards, and track your best score.
- **Upgrade shop** — improve paddle width and movement speed, unlock twin lasers and defensive abilities, and purchase additional lives.
- **Special abilities** — use emergency bombs and row-clearing abilities to deal with difficult brick formations.
- **Power-ups** — collect in-game drops for additional gameplay effects.
- **Custom ball cosmetics** — unlock different ball colors and an Iranian flag skin.
- **Credit economy** — earn credits during gameplay and spend them on permanent upgrades and cosmetics.
- **Persistent progress** — save your high score, best sector, and game-related progression.
- **Procedural assets** — graphics and sound effects are generated by the game; no external asset downloads are required.
- **Audio fallback** — the game can continue without sound if audio initialization fails.

## Gameplay

The objective is to destroy bricks with the ball while keeping it in play using your paddle. Clear each sector to advance, collect power-ups, and use your credits to improve your equipment.

## Requirements

- Python 3.10 or newer
- pip
- Pygame 2.5 or newer, below version 3

## Installation

### Linux

```bash
git clone <YOUR_REPOSITORY_URL>
cd stardrift

python3 -m venv .venv
source .venv/bin/activate

python -m pip install --upgrade pip
python -m pip install -r requirements.txt

python main.py
```

### Windows PowerShell

```powershell
git clone <YOUR_REPOSITORY_URL>
cd stardrift

py -m venv .venv
.\.venv\Scripts\Activate.ps1

python -m pip install --upgrade pip
python -m pip install -r requirements.txt

python main.py
```

If PowerShell blocks virtual-environment activation, use its Python interpreter directly:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

Replace `<YOUR_REPOSITORY_URL>` with the URL of your GitHub repository.

## Controls

| Input | Action |
|---|---|
| `A` / `D` | Move the paddle |
| `Left` / `Right` | Move the paddle |
| Mouse | Move the paddle while holding the left mouse button |
| `Space` | Launch the attached ball or resume |
| `P` | Pause the game |
| `Esc` | Pause, return to the menu, or quit from the menu |
| `R` | Restart the current run or activate the row-clear ability where applicable |
| `Ctrl` | Fire twin lasers when unlocked |
| `Shift` | Activate the defensive barrier when unlocked |
| `M` | Toggle sound |
| Left mouse button | Select menu options and interact with the game |

Some abilities must be unlocked in the shop before they can be used.

## Configuration

Core display and visual settings are defined in `settings.py`, including:

- Window size: `1000 × 700`
- Target frame rate: `120 FPS`
- Window title: `STARDRIFT: Space Paddle`

## Local Data

The game stores local progress and gameplay data on the machine where it runs. These files are excluded from version control by `.gitignore`.

A fresh installation may create its own local data files when the game runs.
